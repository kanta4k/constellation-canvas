# 별자리 캔버스

마우스나 손가락으로 별을 뿌리면 가까운 별끼리 선으로 이어져 별자리가 되는 인터랙티브 캔버스입니다. 빌드나 설치 없이 `index.html` 파일 하나로 동작합니다.

## 실행

`index.html`을 브라우저로 열면 됩니다.

```bash
open index.html
```

## 조작

| 입력 | 동작 |
| --- | --- |
| 마우스 이동 / 터치 드래그 | 별 뿌리기 |
| 클릭 / 탭 | 폭죽 |
| `Space` | 일시정지 / 재생 |
| `G` | 중력 켜기/끄기 (별이 커서로 끌려옴) |
| `C` | 모든 별 지우기 |
| `S` | 현재 화면을 PNG로 저장 |
| `H` | 컨트롤 패널 숨기기/보이기 |
| `1`–`4` | 테마 전환 (은하수 · 오로라 · 석양 · 네온) |

선택한 테마는 브라우저에 저장되어 다음 방문 때도 유지됩니다.
